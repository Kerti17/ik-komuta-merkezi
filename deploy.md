Şimdi projeyi Vercel'e deploy edelim. Adımlar:

1. Projeyi GitHub'a push etmemiz için gereken adımları söyle (git
   init, remote ekleme vb.) — bir GitHub deposu oluşturdum, adı: [ik-komuta-merkezi]

2. Turso'da production veritabanı oluşturmam için tam olarak hangi
   komutları çalıştırmam gerektiğini adım adım söyle, ben terminalde
   çalıştırayım.

3. Turso'dan alacağım bağlantı bilgilerini (DATABASE_URL, AUTH_TOKEN
   gibi) Vercel'de environment variable olarak nereye/nasıl
   ekleyeceğimi söyle.

4. Vercel'de projeyi GitHub deposuna bağlayıp deploy etmemi adım adım
   yönlendir.

5. Deploy tamamlanınca canlı linki bana ver, birlikte test edelim.

Her adımda ne yapacağımı net söyle, ben senin dediklerini uygulayıp
sonucu sana geri bildireyim.
